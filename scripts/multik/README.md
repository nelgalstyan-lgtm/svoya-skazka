# Мультик Алекса — скрипты (08.10)

Писались во временной папке сессии Claude (пути `scratchpad/...` внутри — поправить на свою рабочую папку).
Ключи берутся из `server/.env` (GEMINI_API_KEY, YANDEX_API_KEY) — в файлах их нет.

- `make_prompts.py` — промпты Flow для всех клипов (`Desktop/multik-alex/prompty-2min.txt`, переделки, финал 16–18).
- `stt.mjs` — расшифровка речи клипов с таймингом (Gemini): кто что сказал, не повторилась ли фраза; по ней режем паузы.
- `narr.mjs` — реплики рассказчика (Ермиль neutral, SpeechKit через worker/voice.js).
- `build_v5.py` — монтаж: каждый кусок ровно N кадров + PCM (иначе голос отстаёт), обрезка, цвет, 1080p, заставка/титры/концовка, вставки рассказчика, музыка с приглушением под голосами. Нужны шрифты Lora/Caveat (Google Fonts) и ffmpeg (imageio_ffmpeg).

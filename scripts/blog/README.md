# Блог Героёнка

Статьи блога — файлы `.md` в папке `scripts/blog/posts/`. При сборке сайта `scripts/build-blog.mjs` превращает их в страницы:

- `geroenok.online/blog` — список статей;
- `geroenok.online/blog-<имя-файла>` — статья.

Пока в `posts/` нет ни одной статьи, блог на сайте не появляется: нет ни страницы `/blog`, ни ссылки «Блог» в подвале, ни записей в sitemap. С первой статьёй всё включается само.

## Формат статьи

Имя файла — адрес статьи: только латиница, цифры и дефис, например `chto-podarit-rebenku-na-novyy-god.md`.

```
---
title: Что подарить ребёнку на Новый год: 15 идей, которые запомнятся
description: Короткое описание для Яндекса и Google, 120–160 знаков.
date: 2026-11-20
kicker: Подарки
lead: Подзаголовок под названием (необязательно).
image: assets/blog/podarok.webp
cta: Текст над кнопкой в конце статьи (необязательно; «нет» — без блока).
cta_button: Создать книгу
cta_href: create.html
draft: да
---

Текст статьи. Абзацы — через пустую строку.

## Подзаголовок

- пункт списка
- **жирный**, *курсив*, [ссылка](pricing.html)

> Цитата или совет в рамке.
```

- `date` — дата публикации, ГГГГ-ММ-ДД. Статьи в списке идут от новых к старым.
- `draft: да` — статья не публикуется (черновик).
- Строки, которые начинаются с `<`, вставляются как HTML (например, для материалов для печати).
- Ссылки на страницы сайта пишем с `.html` (`create.html`) — при сборке они превращаются в чистые адреса.

## Важно

- Тексты блога не должны повторять статьи Дзена — иначе Дзен сочтёт статьи там неуникальными и не включит монетизацию.
- Цены, сроки и обещания в статьях сверять с pricing.html и index.html.

# Редизайн сайта по аудиту (19.10.2026)

Полный аудит и ТЗ: https://claude.ai/code/artifact/be0d9875-db30-481c-9200-c6019353277c
(разделы 4 «Визуальная концепция», 6 «Приоритеты», 7 «ТЗ» — там все цифры: палитра, шрифты, UI Kit, порядок блоков).

Главное в трёх пунктах: первый экран продаёт зайца, а не ребёнка в книге; на сайте нет отзывов;
акварель бренда и 3D-книга Алекса не связаны между собой.

## Правила работы

- Редизайн эволюционный: тексты, заяц, акварельные иконки, бумажная фактура остаются.
- Пуш в main = выкладка. Каждый этап — отдельный коммит; перед пушем снимки 1440 и 390 px
  (Chrome headless; для 390 px — через iframe 390 px, иначе окно не сужается) и сравнение с аудитом.
- Общего шаблона нет: шапку, подвал, кнопки менять во всех html.
- Ничего не обещать сверх того, что сайт делает (см. проверку обещаний сайта). Сертификат не показывать.
- Отзывы, фото детей, «фото → рисунок» — только настоящие и с согласия семей. Ничего не выдумывать.

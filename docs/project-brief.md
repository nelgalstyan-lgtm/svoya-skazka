# Бриф проекта «Своя Сказка» — для нового чата

Я делаю сайт для генерации персонализированных электронных детских книг. Вот полный
контекст, чтобы продолжить работу без повторного объяснения с нуля.

## О бизнесе
- Я — ИП в Армении, работаю в основном на русскоязычную аудиторию
- Сайт называется «Своя Сказка», репозиторий: github.com/nelgalstyan-lgtm/svoya-skazka
  (публичный, включён GitHub Pages)
- Оплата: ЮKassa через схему для нерезидентов РФ, расчёт в драмах (AMD) напрямую на
  армянский банковский счёт

## Продукт
- Книга — только электронная (без печати): чтение онлайн + скачивание PDF,
  опционально аудиокнига
- Анкета на сайте собирает: имя, пол, возраст, фото, цвет глаз, тему (приключения/
  сказка/праздник), стиль иллюстраций, и САМОЕ ГЛАВНОЕ — свободное описание характера,
  привычек, словечек, друзей и близких ребёнка (это ключ к персонализации)
- Цены: Короткая история 390₽ (1 hero-иллюстрация), Развёрнутая 790₽ (2-3),
  Большая 1190₽ (4-5) — тарифы отличаются глубиной персонализации и количеством
  иллюстраций с лицом ребёнка

## Архитектура книги (важно!)
Книга состоит из ЧЕРЕДУЮЩИХСЯ ПОРТРЕТНЫХ СТРАНИЦ (не альбомных разворотов):
- **Текстовая страница** — только текст, декоративный дизайн через чистый CSS
  (без AI), СВОЙ уникальный дизайн под каждый из 4 стилей иллюстраций
- **Иллюстративная страница** — полноценная сцена БЕЗ единой буквы текста на ней,
  портретная (~2:3), генерируется AI

Разворот = одна текстовая страница + одна иллюстративная страница рядом.

## Иллюстрации: два типа
1. **Декоративные фоновые сцены** (без ребёнка) — переиспользуются между всеми
   клиентами с одной темой+стилем. Библиотека из 8 тегов сцен для темы «Приключения»:
   структурные (map_table, forest_path, night_camp, treasure_room — нужно 3-4 варианта
   каждой) и специфичные (cave_entrance, mountain_bridge, ship_deck, castle_gate —
   1-2 варианта). Промпты — в файле background-templates-prompts.md
2. **"Геройские" иллюстрации** (с лицом ребёнка) — генерируются под каждый заказ
   индивидуально, движок — Google Gemini (модель Gemini 2.5/3.1 Flash Image,
   она же "Nano Banana"), НЕ InstantID (у него плохое сохранение сходства на детских
   лицах + лицензия только для некоммерческого использования). Промпт — в файле
   story-prompt-template.md

## Ключевые уроки по промпт-инжинирингу для генерации изображений (проверено на практике)
- НИКОГДА не использовать отрицания в описании эмоций ("not angry", "not scared") —
  модели их игнорируют и всё равно тяготеют к упомянутому понятию. Описывать только
  то, что нужно получить, позитивной формулировкой
- Явно указывать точное соотношение сторон (например "portrait aspect ratio ~2:3") —
  иначе модель выбирает случайное, часто слишком широкое/панорамное
- НЕ просить оставить место "for text overlay" — модель может буквально нарисовать
  текст в кадре. Правильно: иллюстрация вообще не содержит текста, текст живёт на
  отдельной странице
- Стиль описывать через ТЕХНИКУ рендеринга (мазки, штриховка, текстуры), а не через
  форму частей лица ("large expressive eyes" ломает точное сохранение формы глаз
  из референсного фото)
- Для сохранения сходства ребёнка — подробно перечислять: facial structure, eye
  shape И eye color, nose shape, lips, hairstyle, hair color, age, отличительные
  черты (веснушки, щербинка и т.п.), и явно писать "do not beautify, idealize,
  or age the character up or down"
- Упрощённые стили (мультяшный) хуже передают тонкие эмоции — там нужно явно
  прописывать более однозначно дружелюбное выражение лица

## Текст истории (LLM-генерация)
Промпт для Claude берёт все поля анкеты и генерирует историю, разбитую на развороты
(spreads), с пометкой type=hero/template и тегом сцены для шаблонных разворотов.
Правила: обязательная драматургическая арка (завязка → происшествие → препятствие →
кульминация → развязка), минимум 120-180 слов на разворот, никаких ярлыков на детские
черты характера (не изображать привычки ребёнка как недостаток), полное соответствие
детскому контенту без исключений. Полный текст промпта — в story-prompt-template.md

## Стили иллюстраций на запуск: 2
Акварель (фирменный стиль) и 3D-мультфильм. Решение 2026-09-24: остальные стили
(мультяшный, классическая графика, аниме, «как нарисовал ребёнок») убраны, чтобы не
растягивать запуск — для каждого стиля нужны свои фоны под все темы. Мультяшный и
классическую графику можно вернуть второй волной: промпты фонов «Путешествия» для них есть
(`server/data/background-prompts-full.json`).

## Тарифы: 2
- «Сказка» (2–7 лет) — 690 ₽: 8 страниц, ребёнок на каждой иллюстрации и на обложке,
  раскраска +190 ₽.
- «Большая история» (6–16 лет) — 1 490 ₽: 6 глав, 3 000–5 000 слов, 8–10 иллюстраций с
  ребёнком и обложка, раскраска включена.
Цены — предварительные, до подключения оплаты.

## Что есть в каждой книге (сделано 2026-09-24 по итогам анализа конкурентов)
- До 3 фото ребёнка → лист персонажа → обложка и все иллюстрации с ребёнком (одинаковая одежда
  и спутники во всей книге)
- Поле «С чем книга может мягко помочь» (страх темноты, первый класс, братик…)
- Продолжение: кнопка в книге переносит анкету и краткое содержание в новую анкету
- «Слушать книгу» (озвучка голосом устройства, бесплатно), QR-код на онлайн-версию на последней странице
- Сертификат «Герой книги», раскраска из иллюстраций
- Бесплатные правки текста прямо в книге и до 3 перерисовок иллюстраций
- Оформление «Сказки» под тему (приключения / сказка / день рождения / Новый год)
- Запрет чужих брендов и персонажей (промпт + проверка текста)
- Сайт: 3D-обложки, сравнение с обычной именной книгой, блок для 8–16 лет, листалка образцов,
  подарочный сертификат (gift.html — оплата и коды появятся вместе с платёжкой), инструкция по печати
- Фото не хранятся; книга (без фото) хранится год
- Решение 2026-09-25: бесплатное превью = весь текст пишется, но клиенту открыты «Сказка» — обложка и 2 страницы,
  «Большая история» — первая глава; рисуются только лист персонажа, обложка и 1 иллюстрация (≈3 картинки).
  Остальное — после оплаты (`POST /api/book/:id/unlock`, пока вручную по ADMIN_KEY; потом — вебхук платёжки).
  Фото до оплаты лежат в `server/data/photos` (не дольше PHOTO_TTL_HOURS=48), после дорисовки удаляются.
- Решение 2026-09-25: фото обязательно — без него заказ не принимается. Фоновые сцены в книге клиента
  не показываются: не нарисовалась иллюстрация — вторая попытка, не вышло и так — страница остаётся текстовой.
  Фоны остаются только в образцах на сайте (examples.html, ?demo=…).

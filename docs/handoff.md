## Решения, которые уже приняты
**Не обсуждать заново**, владелица их уже приняла.

- **Название: «Героёнок».**
  - Выбрано как универсальное (книги, песни, мультики) и свободное: конкурентов с таким названием не нашли.
  - Логотип пишется одним словом, без `<em>`: с `<em>` разваливался на «Геро ёнок».
  - Трафик даёт не бренд, а страницы под запросы («именная книга для ребёнка», «песня с именем ребёнка», «мультфильм с ребёнком по фото»). Данных Wordstat нет: без входа в аккаунт Яндекса они недоступны, владелица может проверить сама.
- **Хостинг: Cloudflare, бесплатно.**
  - Сайт на Pages. Сервер переписывается:
    - Express → Workers;
    - `server/data/photos` и картинки → R2;
    - книги и задачи → D1;
    - фоновое рисование → Queues (или Workflows);
    - удаление фото через 48 ч (`setInterval`) → Cron Triggers.
  - API на **том же домене**: `geroenok.online/api/*` (маршрут Worker'а).
  - Поддомен `api.` владелица отвергла, нужен «нормальный сайт» для SEO.
  - Фронтенд уже готов к этому: `API_BASE` в проде пустой, запросы идут на относительный `/api/...`.
  - Почему Cloudflare: findena.ru владелицы на Cloudflare открывается из Москвы и СПб за 0,3 с. Новости о замедлении Cloudflare в РФ на её сайте не подтвердились.
  - Отвергнуто: Hetzner, OVH и DigitalOcean из РФ режутся (обрыв на 16 КБ); VPS в РФ (OpenAI не принимает запросы из России); Timeweb Казахстан (3 807 ₽/мес).
  - Запасные варианты, если Workers не потянут: Railway ($5–10/мес, доступ из РФ не проверен), RuVDS Алматы (от ~140 ₽/мес, Казахстан есть в списке стран OpenAI).
- **Оплата: ЮKassa для нерезидентов** подходит.
  - Компании не из РФ подключают, иностранных ИП тоже; тарифы как у российских.
  - СБП недоступна; есть карты, SberPay, T-Pay, ЮMoney; выплаты в драмах на армянский счёт.
  - Владелице уточнить у менеджера (8 800 350-46-56, b2b_support@yoomoney.ru): подключение ИП из Армении, выплаты в AMD, нужны ли чеки 54-ФЗ.
- **Стили:** два, «Акварель» (фирменный) и «3D-мультфильм».
- **Тарифы:**
  - «Сказка» (2–7 лет): 690 ₽, 8 страниц, раскраска +190 ₽.
  - «Большая история» (6–16 лет): 1 490 ₽, 6 глав, 8–10 иллюстраций, раскраска входит. Позже, после первых отзывов, можно поднять до 1 790–1 990 ₽.
- **Фото ребёнка обязательно,** 1–3 штуки.
- **Фоновых сцен в книге клиента нет.** Если иллюстрация не нарисовалась, делается вторая попытка. Если и она не удалась, страница остаётся текстовой («Сказка») или иллюстрация убирается («Большая история»).
- **Бесплатное превью:**
  - Весь текст пишется сразу, рисуются только 3 картинки (≈15 ₽): лист персонажа, обложка, 1 иллюстрация.
  - Клиенту открыты обложка и 2 страницы «Сказки» или 1-я глава «Большой истории».
  - Остальное дорисовывается через `POST /api/book/:id/unlock`. Сейчас вручную по `ADMIN_KEY` (или `?admin=КЛЮЧ` на странице книги), потом по вебхуку ЮKassa.
- **Хранение фото:**
  - Фото хранятся не дольше 48 ч до оплаты и удаляются после дорисовки.
  - Книга без фото хранится 1 год.
  - В политике конфиденциальности указана трансграничная передача данных: OpenAI, Gemini, Cloudflare.
- **Правки текста и до 3 перерисовок** доступны только после оплаты.
- **Чужие бренды и персонажи** запрещены в промпте и отсекаются проверкой текста.

## Иллюстрации
- **Основной сервис:** OpenAI `gpt-image-1.5`, среднее качество, ~25 с на картинку. Gemini — запасной, но на его ключе квота на картинки = 0.
- **`gpt-image-2` не берём:** акварель получается «мозаичной», и генерация дольше.
- **Схема:** фото → лист персонажа → обложка и страницы по листу. Одежда и питомец совпадают во всей книге.
- **Проверено на фото Макса** (142×234 px). Примеры лежат на рабочем столе в `svoya-skazka-primery`.
- **Стоимость:** ≈40–50 ₽ на «Сказку», ≈80–100 ₽ на «Большую историю».

## Как запустить локально
- Сайт: `cd svoya-skazka && python -m http.server 8080` → http://localhost:8080
- Сборка для Pages: `bash scripts/build-pages.sh` → `dist/`. В git не попадает. В `dist/` идут только `*.html`, `assets/`, `js/`.
- Сервер: `cd svoya-skazka/server && node index.js` (порт 3000). Ключи в `server/.env`, в git не попадает.
- Образцы книг:
  - Макс, превью: `book.html?job=55555555-5555-5555-5555-555555555555`
  - Макс, полная: `book.html?job=33333333-3333-3333-3333-333333333333`
